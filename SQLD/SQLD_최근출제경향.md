# SQLD (SQL개발자) 최근 출제 경향

> ADsP랑 같이 준비 목록에 있는 자격증이라, 출제 경향부터 감 잡아두려고 정리.

## 시험 구성

- **1과목 데이터 모델링의 이해**
- **2과목 SQL 기본 및 활용**
- 객관식 50문항 / 90분, 총점 60점 이상 합격 + 과목별 40% 미만이면 과락. 응시료 5만원.
- 2026년은 연 4회(60~63회) 시행 — 3/7, 5/31, 8/22, 11/14. 접수는 보통 시험 4~5주 전에 열린다고 함.

## 최근 기출에서 자주 보이는 유형

+ **윈도우 함수(Window Function)**: 그룹 함수와 다르게 행 수를 그대로 유지하면서 집계·순위 계산 결과를 추가 컬럼으로 보여주는 게 핵심 차이. ROWS/RANGE 옵션까지 디테일하게 나올 수 있어서 얕게만 알면 위험하다고 함.
+ **계층형 쿼리(Hierarchical Query)**: 오라클 문법인 `START WITH ~ CONNECT BY` 비중이 압도적으로 높음. 고득점을 노린다면 SQL Server 계열의 CTE(재귀 쿼리)도 가볍게 같이 봐두는 게 안전.
+ 실무 활용도가 높은 SQL 작성·해석 문제 위주로 출제되고, **기출 유형이 반복**되는 경향이 강해서 기출 반복 풀이가 제일 효율적인 전략이라고 한다.

> 결론: 윈도우 함수 + 계층형 쿼리, 이 두 파트를 포기하면 합격선(60점) 넘기기가 빠듯해진다고 하니 이 둘부터 확실히 잡고 시작하자.
